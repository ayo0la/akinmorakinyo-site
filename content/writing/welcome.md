Each `.md` file in this folder is one post. Frontmatter fields:

- `title`, `date` (YYYY-MM-DD), `excerpt`: required
- `tag`: optional label shown on the card (defaults to Essay)
- `publication` + `externalUrl`: set both for pieces published elsewhere
  (for example Nairametrics columns). External posts render as cards that
  link out and have no page here, so no body is needed.
- `draft: true`: hides the post everywhere

Delete this file whenever.
